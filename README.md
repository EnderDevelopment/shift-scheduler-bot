# Shift Scheduler Bot

Effortlessly manage and schedule your Discord shifts with this bot.

## Features

- Create shifts with details like time, duration, type, title, and host
- Subscribe to shifts and receive notifications
- Receive reminders 5 minutes before the shift

## Requirements

- Python 3.8 or higher
- discord.py
- python-dotenv

## Installation

1. Clone the repository
2. Install the required packages using `pip install -r requirements.txt`
3. Create a `.env` file and add your Discord bot token as `DISCORD_TOKEN=your_token_here`
4. Run the bot using `python main.py`

## Usage

1. Invite the bot to your Discord server
2. Use the `/shift` command to create a new shift
3. Fill in the details in the modal that appears
4. Subscribe to the shift using the 'Subscribe' button
5. Receive reminders 5 minutes before the shift

## Configuration

The bot uses a `.env` file for configuration. Add your Discord bot token as `DISCORD_TOKEN=your_token_here`.
